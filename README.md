# MMIN-Converter (WIP)
Simple converter for mm to inches and inches to mm. Meant as a project to advance skills in PCB design and firmware development.

## Prototype
- Button Matrix
- 128x32 OLED
- STM32F103C8 MCU
- TPS63020 buck-boost converter (3.3v)
- TPS61040 boost converter (12v)
- 2xAA battery holder
